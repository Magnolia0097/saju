# 만세력 계산 방식 사전 검증 (2026-11-09)

S01 구현 전에 SPEC 3.3의 계산 방식이 실제로 성립하는지 확인한 기록. 스크립트: `calendar-crosscheck.cjs`
사용 버전: astronomy-engine 2.1.19 · korean-lunar-calendar 0.4.0 · lunar-javascript 1.7.8 · luxon 3.7.2 · Node 22

## 1. 시간 보정 — IANA tzdata(`Asia/Seoul`)로 과거 서머타임·표준시 자동 반영

| 케이스 | 벽시계 | UTC 오프셋 | 보정 시각 (UTC + 8:30) |
|---|---|---|---|
| 1988 서머타임 | 1988-07-15 14:20 | +10:00 | 12:50 |
| 1987 서머타임 | 1987-07-01 12:00 | +10:00 | 10:30 |
| 1988 서머타임 종료 후 | 1988-11-01 12:00 | +09:00 | 11:30 |
| 1954~61 표준시 | 1960-01-15 12:00 | +08:30 | 12:00 |
| 1955~60 서머타임 | 1957-07-15 12:00 | +09:30 | 11:00 |
| 1948~51 서머타임 | 1950-07-01 12:00 | +10:00 | 10:30 |
| 평시 | 1965-07-01 12:00 | +09:00 | 11:30 |
| 현재 | 2026-11-09 12:00 | +09:00 | 11:30 |

→ 서머타임 표를 직접 만들 필요 없음. luxon + tzdata로 UTC 변환 후 고정 오프셋을 더하면 된다.

## 2. 12절 절입 시각 — astronomy-engine 태양 황경 계산

- `lunar-javascript`(중국 표준시 UTC+8 기준 표)와 1900~2100년 12절 **2,412건** 비교 → **최대 차이 1.04분**
- 2026 입춘: 2026-02-04 05:01 KST · 2027 입춘: 2027-02-04 10:46 KST
- 런타임에서는 계산하지 말고 빌드 시 JSON 표로 생성 (Workers CPU 제약)

## 3. 일진(일주) — 산술식 `(율리우스일 + 49) mod 60`, 0 = 갑자

- 1900~2100년 **73,414일** 전부 `lunar-javascript`와 일치 (불일치 0)
- 1900~2049년 `korean-lunar-calendar`(KASI 기준) 간지와도 불일치 0
- 2026-11-09 = 丁亥(정해)일

## 4. 한국 음력 ≠ 중국 음력 — 음력 변환은 반드시 한국 기준

- 1950~2049년 중 **1,348일**에서 한국(`korean-lunar-calendar`)과 중국(`lunar-javascript`) 음력 날짜가 다름
- 예: 양력 1950-03-18 → 한국 음력 1950-01-30, 중국 음력 1950-02-01
- 결론: 음력 입력 변환은 `korean-lunar-calendar`만 사용. `lunar-javascript`는 절입·일진 교차검증용으로만
